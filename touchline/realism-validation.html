The interval comes from resampling the 8 matches by whole match 2,000 times. The improvement is the constant-baseline error minus the model error, so a positive value favours the model. When the interval crosses zero, the improvement cannot be called stable. The data comes from a single competition, and the number of events is not the number of independent matches.

Boundaries: these 8 test matches had been inspected before, so this is a reproduction and a scale check rather than a fresh blind test. Real pressure annotations and the synthetic 3-metre distance marker are not measured on the same basis. Real events can only validate outcome probabilities and event statistics; the route feasibility index, the counterfactual rollout and the run positioning on the analysis page have no real-tracking validation. The outcome score in the synthetic run is sampled by the generator itself, so internal consistency must not be read as real accuracy. Backpasses, ball-retention zones and support still need work.

New: actions and decisions are evaluated separately

Open the upgraded action analysis page · Upgrade check record

A location-value model trained on real events: the target is a goal within at most 10 eligible on-ball actions of the same simplified possession. Tested on 5035 actions, with 29 overlapping goal windows (not a count of independent goals); Brier 0.005493, constant training baseline 0.005727. This only shows that location value has preliminary support; it does not mean the ranking of alternative options has been validated.

Passing, carrying, shooting and waiting all use the same value unit. The lane defensive adjustment and the possession retention weights for carry / wait remain rule assumptions. The sensitivity range is not a confidence interval. The actual execution outcome is revealed separately at the replay time and never feeds back into the pre-action score; without body orientation and touch information, no technical quality score is given.

Data source, splits and limits

Source: StatsBomb Open Data / Hudl, 2022 World Cup. The first 32 matches are taken in match_id order: 16 calibration matches, 8 development check matches and another 8 as the final test. The first-round development results are kept, and the final test was not used to modify the policy.

Filter: both halves, Regular Play, footed ground passes / footed shots, with Carry included. Event counts are not equivalent decision opportunities, so regional action frequencies are only a reference for generation weights. The sample is not representative of the Premier League.

The data has no continuous tracking, so defensive positioning, body orientation, preferred foot, full collision physics and actions that did not occur cannot be validated. The original simplified shot save ratio, the handling of unsuccessful passes and the carry after a restart are still kept. The route feasibility index on the new analysis page is still an independent heuristic model, not a success probability produced by this calibration.

The raw data files are kept locally under .local/statsbomb and are not distributed publicly with the project; the profile and the validation JSON record the source URL, the version, the checksum and the training / test match IDs. When publishing results derived from the data, please follow the terms of the source repository and add the required StatsBomb attribution.
