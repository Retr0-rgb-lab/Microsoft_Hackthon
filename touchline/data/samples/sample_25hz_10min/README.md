# sample_25hz_10min

Synthetic 25 Hz tracking clip (10 minutes in the full file, centre-origin metres). The bundle is described in [`../README.md`](../README.md). Schema and the axis map are in [`../../../scripts/synth/FORMAT.md`](../../../scripts/synth/FORMAT.md).

| File | Role |
| --- | --- |
| `metadata.json` | `frame_hz` 25, 22 players, column layout |
| `tracking.jsonl` | Full match, 15001 frames, about 17 MB. Checked in. |
| `events.jsonl`, `states.jsonl`, `summary.json`, `validation_report.json` | Rest of the sample bundle. |
